# Weather App на Express + Axios

Цей проєкт — простий веб-сервер на Node.js з використанням Express та Axios, який отримує поточну погоду через Open-Meteo API та відображає її на сторінці.

## 🔧 Використані технології

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [Axios](https://axios-http.com/)
- [EJS](https://ejs.co/) (або інший шаблонізатор, якщо використовується)
- [Open-Meteo API](https://open-meteo.com/)

## 🚀 Запуск

1. Клонуй репозиторій:
   ```bash
   git clone https://github.com/your-username/weather-app.git
   cd weather-app
2. Встанови залежності:
   npm install
3. Запусти сервер:
   node index.js або nodemon index.js
4. Перейди в браузері:
   http://localhost:3000
